本目录保留已有计算记录，供正文第11.3节的一句限制说明追溯；此次正文精简没有重新求解，也没有将粗网格结果改写为精细二维结论。

- `endpoint_audit.json`：既有二维局部续算的设置、结果和误差范围说明，原字节复制。第四问记录在 `cases.q4`。
- `q4_direct_execution_field.npz`：既有第四问二维保存场，原字节复制。`time_s` 为秒；`states` 的维度顺序为时间、轴向、径向、温湿分量，最后一维第0项为温度，第1项为干基含水率。

第四问正式时刻为183931.56 s（51.0921 h）。原80×128网格的全节点最大含水率为0.15000140662294265 kg/kg，略高于0.15阈值。该场由已有粗网格前史局部续算得到；它既不能直接推翻精细一维结果，也不能证明该时刻的精细二维全域已经达标。

现行论文将51.0921 h保留为指定条件下的一维径向模型执行时长。正文移除了完整二维终点讨论，但此处的原始结果和限制保持不变。

只读检查可用NumPy加载NPZ（`allow_pickle=False`），在`time_s`中定位183931.56，再对对应`states[..., 1]`取最大值。运行原审查程序会积分并写文件，本目录仅用于读取已有证据。
